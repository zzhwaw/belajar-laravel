# Kamus Git

## Perintah Dasar

- `git status`: memeriksa kondisi working tree.
- `git branch --show-current`: melihat branch aktif.
- `git switch -c nama-branch`: membuat dan berpindah ke branch baru.
- `git stash push -m "pesan"`: menyimpan sementara perubahan yang sudah dilacak.
- `git stash list`: melihat daftar stash.
- `git stash apply`: menerapkan kembali perubahan dari stash.
- `git stash pop`: menerapkan perubahan sekaligus menghapus stash dari daftar jika berhasil.
